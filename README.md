# GitHub 新手入门教程 🚀

这是一个为完全零基础的新手准备的 GitHub 使用指南。本项目通过一个直观的网页，带你一步步了解 GitHub 的核心操作，让你在 30 分钟内轻松上手。

## 📖 项目简介

这个网页详细介绍了 GitHub 的基础概念和操作，包括：
- 名词大扫盲：40 个词条分 8 大类（核心概念/分支协作/上传下载/社区互动/文件开源/连接安全/电脑基础词/进阶工具），带搜索框可以随时查，还有 Git/GitHub/版本控制的关系图
- 详细教程：注册账号 → 装 Git → 本地提交 → 连接远程仓库 → 分支协作 → 参与开源 → 打造自己的项目主页，每步都写清楚"在哪输入、为什么、会看到什么"
- 常见问题：12 个高频坑（安装失败、SSH 报错、push 被拒、中文乱码…），现象→原因→解决步骤
- 附录：22 条命令速查表 + 官方学习资源链接
